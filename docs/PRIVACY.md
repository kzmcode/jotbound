# データの送信と保存（プライバシー）

Jotbound は、利用者が**自分の Firebase プロジェクト**にデプロイして使うアプリです。開発者を含む第三者が運営する共通のサーバーやデータベースはありません。ここでは、どのデータが**どこに保存され、どこへ送信されるか**をまとめます。

> 2026-10-27 時点の内容です。各サービスの規約は変わることがあるので、リンク先の最新版も確認してください。

## 保存する場所

| データ | 保存する場所 | 消えるとき |
| --- | --- | --- |
| 本・メモ（文字起こしを含む）・タグ・設定 | あなたの Firebase プロジェクトの Cloud Firestore（`users/{UID}/` 以下） | アプリで削除したとき、または Firebase プロジェクトを削除したとき |
| 上と同じデータのコピー | 端末内の Firestore キャッシュ（オフラインで表示するため） | ログアウトしても残ることがあります。ブラウザのサイトデータを消すと消えます |
| 録音の音声・解析結果・入力途中の内容（下書き） | 端末内の IndexedDB だけ（録音したアカウントでログインしているときだけ表示） | 保存・破棄したとき、またはブラウザのサイトデータを消したとき |
| 表示テーマ、送信の説明への同意 | 端末内の localStorage | ブラウザのサイトデータを消したとき |

- **音声はクラウドに保存しません:** 音声を Firestore や Cloud Storage に保存することはありません。
- **下書きが失われることがあります:** ブラウザのサイトデータを消すと、保存していない録音の下書きは失われます。
- **共有の端末では注意してください:** 共有の端末では、使い終わったらログアウトし、必要ならブラウザのサイトデータを消してください。

## 送信する先

| 送信先 | 送るもの | 目的 | 関係する規約 |
| --- | --- | --- | --- |
| Google（Firebase AI Logic → Gemini Developer API） | 録音の音声、抽出の指示文、登録済みの書名（最大 20 冊）、既存のタグ名（種類ごとに最大 30 件） | 文字起こしと項目の抽出 | [Gemini API 追加利用規約](https://ai.google.dev/gemini-api/terms) / [AI Logic のデータの扱い](https://firebase.google.com/docs/ai-logic/data-governance) |
| Google（Firebase Authentication） | Google アカウントの情報（名前・メール・UID） | ログイン | [Firebase の利用規約](https://firebase.google.com/terms) |
| Google（Cloud Firestore） | 本・メモ・タグ・設定 | 保存と同期 | 同上 |
| Google（App Check / reCAPTCHA Enterprise） | ブラウザや操作に関する情報 | 不正なアクセスの判定 | [reCAPTCHA の利用規約](https://cloud.google.com/terms/service-terms) |
| Google Books API | 検索した ISBN・書名 | 書誌の検索・書影 | [Google Books API の利用規約](https://developers.google.com/books/terms) |
| Open Library Covers | ISBN（画像 URL に含まれる） | 書影の表示 | [Open Library](https://openlibrary.org/dev/docs/api/covers) |

アプリ自体には、広告・アクセス解析・トラッキングのための送信はありません。

## AI に音声を送るとき

- **送る前に確認します:** 初めて解析する前に説明を表示し、同意してから送信します。同意しなくても、録音を聞きながら手入力でメモを保存できます。
- **1件の解析で1回だけ送ります:** 失敗しても自動では再送しません。再試行と再解析は、利用者が操作したときだけです。
- **無料枠では、送った内容が Google のサービス改善に使われます:**
  - Jotbound は Cloud Billing を紐付けない Spark プランで使う前提です。この場合、Gemini API は「無料のサービス（Unpaid Services）」として扱われます。
  - [Gemini API 追加利用規約](https://ai.google.dev/gemini-api/terms)（2026-04-28 更新）では、無料のサービスに送った内容と生成された応答は、Google のサービスの提供・改善・開発に使われ、人が読んで注釈を付けることがあると定められています。
  - 同じ規約は、無料のサービスに機密情報や個人情報を送らないよう求めています。
  - **機密情報や他人の個人情報は録音しないでください。** 本の引用と自分の感想にとどめることをおすすめします。

## バックアップファイル

- **JSON の中身:** 設定画面から書き出す JSON には、本・メモ（文字起こしを含む）・タグ・選択中の本が入ります。
- **含まないもの:** 録音の音声、下書き、API キー、ログイン情報は含みません。
- **保管:** ファイルは端末内で作るだけで、どこにも送信しません。保管場所には注意してください。

## データの削除

- **個別に削除する:** メモ・本・タグは、アプリの画面から削除できます。
- **すべて削除する:** Firebase コンソールの Firestore で `users/{UID}` 以下を削除するか、Firebase プロジェクトごと削除します。
- **端末内のデータ:** ブラウザの設定で、このサイトのデータを削除します。
